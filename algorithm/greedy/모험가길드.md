# 🏕️ 모험가 길드

## 📌 문제 요약

- 각 모험가는 공포도 X를 가짐.
- 공포도 X인 모험가는 **X명 이상이 있는 그룹**에만 속할 수 있음.
- 모든 모험가를 적절히 그룹지어 **최대 몇 개의 그룹**을 만들 수 있는지 구하라.

---

## 📥 입력 형식

```
첫째 줄: 모험가의 수 N (1 ≤ N ≤ 100,000)
둘째 줄: 공포도의 값들이 공백으로 구분되어 주어짐
```

---

## 📤 출력 형식

```
만들 수 있는 그룹의 최대 수 출력
```

---

## 🧠 제약 조건

- 최대 N = 100,000 → **O(N log N)** 이하 알고리즘 필요
- 공포도는 1 이상 N 이하의 자연수

---

## 🔍 예제

입력:

```
5
2 3 1 2 2
```

정렬 후:

```
1 2 2 2 3
```

그룹 1: `[1]`  
그룹 2: `[2, 2]`  
남은 `[2, 3]`은 그룹 불가 → 총 **2개 그룹**

---

## 💡 풀이 아이디어 (그리디)

- 공포도가 낮은 사람부터 정렬
- 사람을 하나씩 그룹에 추가하다가, 현재 그룹 인원이 공포도 이상이면 → 그룹 결성
- 그룹이 만들어지면 인원 수 초기화

---

## 🔢 풀이 단계

1. 공포도를 오름차순으로 정렬
2. 하나씩 탐색하며 그룹에 추가
3. 현재 그룹 인원이 해당 공포도 이상이면 그룹 결성
4. 반복

---

## ✅ 코드 (Python)

```python
n = int(input())
fear = list(map(int, input().split()))
fear.sort()

result = 0  # 최종 그룹 수
count = 0   # 현재 그룹 인원

for f in fear:
    count += 1
    if count >= f:
        result += 1
        count = 0

print(result)
```

---

## 📘 핵심 개념 요약

- **그리디 알고리즘**: "지금 가능한 그룹을 최대한 빨리 만든다"
- **정렬 + 조건 탐색**이 핵심
- 공포도가 낮은 순서대로 묶는 것이 항상 유리하다
