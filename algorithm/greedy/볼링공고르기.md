# 🎳 볼링공 고르기 - 문제 풀이 템플릿

## 📌 문제 요약

- 볼링공 N개가 있고, 각 볼링공은 1 ~ M 사이의 무게를 가짐
- 두 사람은 서로 다른 볼링공을 하나씩 선택함
- **같은 무게의 공은 중복 불가 (서로 다른 공이지만 무게가 같으면 X)**
- 서로 **다른 무게**의 두 공을 고르는 경우의 수를 구하라

---

## 📥 입력 형식

```
첫째 줄: 볼링공 개수 N, 공 무게 범위 M (1 ≤ N ≤ 1,000, 1 ≤ M ≤ 10)
둘째 줄: N개의 공 무게 (1 ≤ 무게 ≤ M)
```

---

## 📤 출력 형식

```
조건을 만족하는 경우의 수
```

---

## 🧠 제약 조건

- N ≤ 1,000 → `O(N^2)` 가능하지만 더 효율적인 풀이 필요
- 무게 종류 M ≤ 10 → 무게별 카운팅 배열 사용 가능

---

## 🔍 예제

입력:

```
5 3
1 3 2 3 2
```

- 무게별 개수:
  - 1: 1개
  - 2: 2개
  - 3: 2개

가능한 서로 다른 무게 조합:

- (1,2): 1×2 = 2
- (1,3): 1×2 = 2
- (2,3): 2×2 = 4

총합: 2 + 2 + 4 = **8**

---

## 💡 풀이 아이디어 (그리디 + 누적합)

- 무게별 개수를 저장한 뒤,
- 하나의 무게를 기준으로, 그 이후 무게들과의 조합 수를 누적하며 계산
- 즉, 중복 제거 & 효율적 계산

---

## 🔢 풀이 단계

1. 무게별 공 개수를 리스트에 저장 (index = 무게)
2. 전체 볼링공 수에서 현재 무게 개수만큼 차감하며 조합 수 계산
3. `경우의 수 += 현재 무게 개수 × 남은 공 수`

---

## ✅ 코드 (Python)

```python
n, m = map(int, input().split())
weights = list(map(int, input().split()))

count = [0] * (m + 1)

# 각 무게별 개수 세기
for w in weights:
    count[w] += 1

result = 0
for i in range(1, m + 1):
    n -= count[i]  # i보다 큰 무게와만 조합 가능
    result += count[i] * n

print(result)
```

---

## 📘 핵심 개념 요약

- 단순 이중 반복문은 `O(N^2)` 이지만,
- 무게별 개수 저장 → **무게별 누적 조합 계산**으로 `O(M)` 수준 최적화 가능
- 무게 범위가 작기 때문에 **count 배열**을 활용한 전략이 매우 효과적
