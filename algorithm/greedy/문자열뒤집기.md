# 🔄 문자열 뒤집기

## 📌 문제 요약

- 0과 1로 이루어진 문자열이 주어짐
- 연속된 숫자들을 한 번에 모두 뒤집을 수 있음
- 문자열을 모두 같은 숫자로 만들기 위한 **최소 뒤집기 횟수**를 구하라

---

## 📥 입력 형식

```
0과 1로만 이루어진 문자열 S (1 ≤ |S| ≤ 1,000,000)
```

---

## 📤 출력 형식

```
모두 같은 숫자로 만들기 위한 최소 뒤집기 횟수
```

---

## 🧠 제약 조건

- 문자열 길이 최대 1,000,000 → **O(N)** 이하 알고리즘 필요
- 덩어리(그룹) 단위로 연산 가능

---

## 🔍 예제

입력:

```
0001100
```

0 | 0 | 0  
→ 1 덩어리  
1 | 1  
→ 1 덩어리  
0 | 0  
→ 1 덩어리

총 덩어리 수:

- 0 그룹: 2개
- 1 그룹: 1개

→ 더 적은 쪽인 **1 그룹만 뒤집기** → 정답: **1**

---

## 💡 풀이 아이디어 (그리디)

- 연속된 숫자가 바뀔 때마다 **새 그룹 시작**으로 판단
- '0 그룹 수' 와 '1 그룹 수'를 각각 세어서
- 그 중 **작은 값**이 최소 뒤집기 횟수

---

## 🔢 풀이 단계

1. 문자열의 첫 글자 기준으로 첫 그룹 카운트
2. 두 번째 문자부터 탐색하면서, 이전 문자와 다르면 새 그룹 카운트
3. 그룹이 '0'이면 `count0 += 1`, '1'이면 `count1 += 1`
4. `min(count0, count1)` 출력

---

## ✅ 코드 (Python)

```python
s = input()

count0 = 0
count1 = 0

# 첫 문자 기준 초기 그룹 셈
if s[0] == '0':
    count0 += 1
else:
    count1 += 1

# 그룹 변화 감지
for i in range(1, len(s)):
    if s[i] != s[i - 1]:
        if s[i] == '0':
            count0 += 1
        else:
            count1 += 1

print(min(count0, count1))
```

---

## 📘 핵심 개념 요약

- **그리디 알고리즘**: 가능한 한 적은 덩어리만 뒤집기
- 문제의 포인트는 **연속된 숫자 블록** 단위로 뒤집는 것
- 결과적으로 **0 블록 수 vs 1 블록 수 중 작은 값**이 정답
