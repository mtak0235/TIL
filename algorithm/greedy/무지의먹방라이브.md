# 🍜 무지의 먹방 라이브

## 📌 문제 요약

- N개의 음식이 번호순으로 쌓여 있음
- 음식 1번부터 순서대로 1초씩 먹음 (0초엔 음식 1번, 1초엔 음식 2번…)
- 마지막 음식 다음엔 다시 음식 1번으로 순환
- 각 음식마다 먹는 시간이 정해져 있음 (`food_times`)
- K초 후에 **먹고 있던 음식 번호**를 반환 (없으면 -1)

---

## 📥 입력 형식

```python
food_times = [3, 1, 2]  # 각 음식 먹는 시간
k = 5                   # 방송 중단 시간
```

---

## 📤 출력 형식

```
먹고 있던 음식 번호
```

---

## 🧠 제약 조건

- 음식 수 N ≤ 200,000
- K ≤ 2 \* 10^13

→ 단순 `O(K)` 시뮬레이션 ❌ (시간 초과)
→ **우선순위 큐 + 누적 계산** 사용 필요 ✅

---

## 🔍 예제

```python
food_times = [3, 1, 2]
k = 5
```

초별 상태:

- 0초: 1번 (3→2)
- 1초: 2번 (1→0)
- 2초: 3번 (2→1)
- 3초: 1번 (2→1)
- 4초: 3번 (1→0)
- 5초: **1번이 현재 먹고 있는 음식** → 정답: `1`

---

## 💡 풀이 아이디어 (우선순위 큐)

- 먹는 시간이 가장 적은 음식부터 제거하며 전체 사이클 시간 감소
- 한 사이클에 걸리는 시간 = `가장 작은 음식 시간 - 이전 음식 시간` × 남은 음식 수
- K보다 작으면 해당 사이클 모두 제거 가능
- 마지막에 남은 음식 리스트에서 `k % 남은 음식 수` 번째 음식이 정답

---

## 🔢 풀이 단계

1. 음식 정보를 `(time, index)` 형태로 우선순위 큐에 저장
2. `전체 시간 누적`과 `이전 최소값` 추적
3. 현재 최소값 기준으로 한 바퀴 도는 데 걸리는 시간 계산
4. K보다 작으면 처리하고 다음으로 진행
5. K보다 작지 않으면 → 남은 음식 리스트를 **index 기준 정렬**
6. `k % 남은 음식 수` 번째 음식 index 출력

---

## ✅ 코드 (Python)

```python
import heapq

def solution(food_times, k):
    if sum(food_times) <= k:
        return -1

    q = []
    for i, t in enumerate(food_times):
        heapq.heappush(q, (t, i + 1))  # (time, index)

    total_time = 0     # 누적 시간
    previous = 0       # 이전 최소값
    n = len(food_times)

    while q:
        # 현재 라운드 전체 소요 시간 계산
        time_to_consume = (q[0][0] - previous) * n
        if total_time + time_to_consume > k:
            break
        current_time = heapq.heappop(q)[0]
        total_time += (current_time - previous) * n
        previous = current_time
        n -= 1  # 하나 제거됨

    # 남은 음식 중에서 k초 후에 먹을 음식 찾기
    result = sorted(q, key=lambda x: x[1])  # index 기준 정렬
    return result[(k - total_time) % n][1]
```

---

## 📘 핵심 개념 요약

- 핵심은 `전체 시간`을 효율적으로 **일괄 처리**하는 것
- `(최소값 - 이전값) * 남은 개수` 계산이 중요
- 힙을 활용한 시간 복잡도: `O(N log N)`
