# 💸 만들 수 없는 금액

## 📌 문제 요약

- N개의 동전이 주어짐 (각 동전은 자연수)
- 이 동전들을 이용해서 **만들 수 없는 최소 금액**을 구하라
- 단, **동전은 모두 사용하지 않아도 되며, 중복 없이 사용**

---

## 📥 입력 형식

```
첫째 줄: 동전 개수 N (1 ≤ N ≤ 1,000)
둘째 줄: N개의 동전 가치 (각각 1 ≤ ≤ 1,000,000)
```

---

## 📤 출력 형식

```
동전들로 만들 수 없는 가장 작은 양의 정수
```

---

## 🧠 제약 조건

- N ≤ 1,000 → **O(N log N)** 가능 (정렬 필요)
- 동전 가치는 최대 1,000,000이지만, 동전 개수만큼의 조합으로 생각
- 누적합 방식으로 문제 해결 가능

---

## 🔍 예제

입력:

```
5
3 2 1 1 9
```

정렬 후: `1 1 2 3 9`

처리:

- 1 → 만들 수 있음 → 현재 누적합: 1
- 1 → 만들 수 있음 → 누적합: 2
- 2 → 1~3 가능 → 누적합: 4
- 3 → 1~7 가능 → 누적합: 7
- 9 → **7 < 9이므로** → **정답: 8**

---

## 💡 풀이 아이디어 (그리디)

- 동전을 **오름차순으로 정렬**
- 누적합 `target`을 관리하며 다음 동전을 확인
- `target`보다 큰 동전이 등장하면 → 그 `target`이 만들 수 없는 최소 금액

---

## 🔢 풀이 단계

1. 동전 리스트 정렬
2. `target = 1`로 시작 (현재까지 만들 수 있는 금액 + 1)
3. 각 동전을 순회하며:
   - 만약 `coin > target` → 정답은 target
   - 그렇지 않으면 `target += coin`
4. 루프 끝나면 마지막 target이 정답

---

## ✅ 코드 (Python)

```python
n = int(input())
coins = list(map(int, input().split()))
coins.sort()

target = 1
for coin in coins:
    if coin > target:
        break
    target += coin

print(target)
```

---

## 📘 핵심 개념 요약

- **그리디 알고리즘**: 매 순간 가장 적은 금액부터 고려하여 확장
- "지금까지 만들 수 있는 금액의 범위"를 유지하며 진행
- 그 범위를 넘는 순간이 → 만들 수 없는 첫 금액
