# ➕✖️ 곱하기 혹은 더하기

## 📌 문제 요약

- 0부터 9까지의 숫자로 이루어진 문자열이 주어짐.
- 왼쪽에서 오른쪽으로 숫자를 하나씩 보면서 **'더하기' 혹은 '곱하기'** 를 선택해 **가장 큰 수**를 만들기.
- 연산 순서는 항상 왼쪽에서 오른쪽으로 진행됨.

---

## 📥 입력 형식

```
숫자 문자열 S (1 ≤ S의 길이 ≤ 20)
```

---

## 📤 출력 형식

```
만들 수 있는 가장 큰 수
```

---

## 🧠 제약 조건

- 문자열 길이가 짧아서 **O(N)** 으로 충분함 (N ≤ 20)
- 숫자 중 0이나 1이 있을 수 있음 → **곱하기보다는 더하는 것이 나음**

---

## 🔍 예제

입력:

```
02984
```

처리:

```
0 + 2 = 2
2 * 9 = 18
18 * 8 = 144
144 * 4 = 576
```

정답: **576**

---

## 💡 풀이 아이디어 (그리디)

- 각 숫자를 왼쪽에서 하나씩 확인
- **현재 결과값이 1 이하**이거나 **현재 숫자가 0 또는 1**이면 `+`가 유리함
- 그 외에는 `*`가 유리하므로 곱셈 수행

---

## 🔢 풀이 단계

1. 첫 번째 숫자를 결과값으로 초기화
2. 두 번째 숫자부터 반복:
   - 현재 숫자 or 결과값 중 하나라도 ≤ 1이면 `+`
   - 둘 다 2 이상이면 `*`

---

## ✅ 코드 (Python)

```python
s = input()
result = int(s[0])

for i in range(1, len(s)):
    num = int(s[i])
    if result <= 1 or num <= 1:
        result += num
    else:
        result *= num

print(result)
```

---

## 📘 핵심 개념 요약

- **그리디 알고리즘**: "지금 가장 좋은 선택을 고른다"
- 1 또는 0이 나올 때는 **덧셈이 유리**하다는 점이 핵심
- 숫자가 커질수록 곱셈이 덧셈보다 훨씬 큼
