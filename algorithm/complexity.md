# ⏱️ 시간 복잡도별 입력 크기 한계표

| 시간 복잡도    | 대략 허용되는 입력 크기 (N) | 설명                          |
| -------------- | --------------------------- | ----------------------------- |
| O(1), O(log N) | 거의 무제한 (N ≤ 천만 이상) | 상수/로그 시간                |
| O(N)           | 최대 약 1,000만             | 선형 탐색 가능                |
| O(N log N)     | 최대 약 10만                | 정렬, 이진 탐색 기반 알고리즘 |
| O(N^2)         | 최대 약 2,000               | 이중 for문, 브루트포스 탐색   |
| O(N^3)         | 최대 약 500                 | 삼중 for문, 플로이드-워셜 등  |
| O(2^N)         | 최대 약 20                  | 부분 집합, 백트래킹 등        |
| O(N!)          | 최대 약 10                  | 순열, 완전탐색                |

> ⚠️ 위 수치는 **Python 기준**, 일반적인 코딩 테스트 환경에서 시간 제한 1~2초 기준으로 추정한 값입니다.
