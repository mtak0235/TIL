## 🐍 백준 3190번 - 뱀

### ✅ 문제 요약

- N x N 보드에서 뱀이 오른쪽으로 이동 시작
- 사과를 먹으면 몸이 길어짐 (안 먹으면 꼬리 줄임)
- 벽이나 자기 몸에 부딪히면 게임 종료
- 방향 전환 정보(L, D)를 시간 기준으로 입력받음
- 게임이 종료되는 "시간(초)"을 출력

---

### ✅ 핵심 포인트 정리

| 항목          | 내용                                                                                                      |
| ------------- | --------------------------------------------------------------------------------------------------------- |
| 알고리즘 분류 | 구현, 시뮬레이션, 큐                                                                                      |
| 자료구조 사용 | `deque`로 뱀 위치 관리, `dict`로 방향 전환 시점 저장                                                      |
| 시간 복잡도   | O(T), 최대 이동 시간 T는 N² 이하로 충분히 가능                                                            |
| 주의사항      | - 좌표 입력은 1-based → 내부에서는 0-based로 처리<br> - 회전은 방향 배열을 시계 방향/반시계 방향으로 조작 |

---

### ✅ 입력 예시

```
6
3
3 4
2 5
5 3
3
3 D
15 L
17 D
```

- 보드 크기: 6x6
- 사과 위치: (3,4), (2,5), (5,3)
- 방향 전환: 3초 후 D(오른쪽), 15초 후 L(왼쪽), 17초 후 D(오른쪽)

---

### ✅ 출력 예시

```
9
```

---

### ✅ 해결 전략 요약

1. **방향 배열 설정**: `오 → 아래 → 왼 → 위` 순서 (`dx`, `dy`)
2. **뱀 위치를 deque로 관리** (머리 추가, 꼬리 삭제)
3. **매초 이동 반복**:
   - 벽/몸과 부딪히면 종료
   - 사과 있으면 꼬리 유지
   - 사과 없으면 꼬리 삭제
4. **정해진 시간에 방향 전환** 적용
5. 이동하다 부딪히면 시간 출력하고 종료

---

### ✅ 예외 및 주의사항

- 사과를 먹을 때는 꼬리를 줄이지 않는다.
- 회전은 **해당 시간이 지난 직후에 수행**
- `1-based 좌표` 입력을 `0-based`로 변환해야 충돌/사과 처리 시 오류 없음
- 이동 후 충돌 여부 체크 시, 다음 위치를 미리 계산해서 처리

---

### ✅ 예시 코드 (Python)

```python
from collections import deque

def turn(direction, c):
    if c == 'L':
        return (direction - 1) % 4
    else:
        return (direction + 1) % 4

n = int(input())
k = int(input())
board = [[0] * n for _ in range(n)]
for _ in range(k):
    x, y = map(int, input().split())
    board[x-1][y-1] = 1  # 사과는 1로 표시

l = int(input())
directions = dict()
for _ in range(l):
    t, d = input().split()
    directions[int(t)] = d

dx = [0, 1, 0, -1]  # 동 남 서 북
dy = [1, 0, -1, 0]

x, y = 0, 0
board[x][y] = 2  # 뱀이 있는 위치는 2
direction = 0
time = 0
snake = deque()
snake.append((x, y))

while True:
    time += 1
    nx = x + dx[direction]
    ny = y + dy[direction]

    if not (0 <= nx < n and 0 <= ny < n) or board[nx][ny] == 2:
        break  # 벽 또는 자기 몸에 부딪힘

    if board[nx][ny] == 1:
        board[nx][ny] = 2
        snake.append((nx, ny))  # 사과 있음: 꼬리 안 줄임
    else:
        board[nx][ny] = 2
        snake.append((nx, ny))
        tx, ty = snake.popleft()
        board[tx][ty] = 0  # 사과 없음: 꼬리 줄임

    if time in directions:
        direction = turn(direction, directions[time])

    x, y = nx, ny

print(time)
```
