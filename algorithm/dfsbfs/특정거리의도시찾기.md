## 🏙️ 백준 18352번 - 특정 거리의 도시 찾기

### ✅ 문제 요약

- N개의 도시, M개의 도로가 있는 방향 그래프
- 모든 도로의 거리는 1
- 특정 출발 도시 X에서 시작해서 **최단 거리가 정확히 K인 도시들**을 모두 출력
- 존재하지 않으면 -1 출력

---

### ✅ 핵심 포인트 정리

| 항목          | 내용                                                                    |
| ------------- | ----------------------------------------------------------------------- |
| 알고리즘 분류 | 그래프 탐색, 최단 경로                                                  |
| 사용 알고리즘 | **BFS** (간선 가중치가 모두 1일 때는 Dijkstra 대신 BFS로 충분)          |
| 시간 복잡도   | O(N + M)                                                                |
| 자료구조      | `deque`, `인접 리스트`, `거리 저장 리스트`                              |
| 주의사항      | - 단방향 그래프임<br> - 도시 번호는 1-based, 리스트는 0-based 처리 유의 |

---

### ✅ 입력 예시

```
4 4 2 1
1 2
1 3
2 3
2 4
```

- 도시 수: 4
- 도로 수: 4
- 거리 K: 2
- 출발 도시 X: 1
- 도로 정보: (1→2), (1→3), (2→3), (2→4)

---

### ✅ 출력 예시

```
4
```

---

### ✅ 해결 전략 요약

1. **인접 리스트로 그래프 구성**
2. **거리 배열(distance)**을 `-1`로 초기화 (방문 여부도 겸함)
3. 출발 도시 X부터 **BFS 탐색**으로 모든 거리 계산
4. `distance[i] == K`인 도시를 오름차순 출력
5. 아무 도시도 없으면 `-1` 출력

---

### ✅ 예외 및 주의사항

- 도시 번호는 1부터 시작 → 배열 접근 시에는 -1 조정하거나, 그대로 1-based로 쓰는 것도 가능
- BFS는 방문한 노드를 다시 방문하지 않으므로 **최단 거리**를 구할 수 있음
- 여러 도시가 출력될 수 있으니 **오름차순 정렬** 필요

---

### ✅ 예시 코드 (Python)

```python
from collections import deque

def bfs(start, graph, distance, K):
    queue = deque([start])
    distance[start] = 0
    while queue:
        now = queue.popleft()
        for next_city in graph[now]:
            if distance[next_city] == -1:
                distance[next_city] = distance[now] + 1
                queue.append(next_city)

n, m, k, x = map(int, input().split())
graph = [[] for _ in range(n + 1)]

for _ in range(m):
    a, b = map(int, input().split())
    graph[a].append(b)

distance = [-1] * (n + 1)
bfs(x, graph, distance, k)

found = False
for i in range(1, n + 1):
    if distance[i] == k:
        print(i)
        found = True

if not found:
    print(-1)
```

---

### ✅ 기타 팁

- 거리가 모두 1일 땐 BFS가 최적
- `distance[]`를 -1로 초기화하면 방문 여부 + 거리 동시에 처리 가능
- 거리 조건 정확히 일치하는 것만 출력해야 함 (이하 아님!)
